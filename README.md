# CodingTests
Just to make sure - I am not going to write any coding test again unless paid for, especially because:
- Some coding tests look to be individually usable parts. Most of them then are used in a way that is fully out of my control. I know more than two people who told that this is an optimal way to outsource coding jobs so that they are done in the applicants best fashion, they receive the code and pay nothing. They even as the person to put the code on github or such so it goes under GPL/LGPL or whatever so it can be fully utilized
- That kind of take away coding tests take several hours or some days to write, so it is way behind necessary assessment of skills. The interviewer will say do this, just an hour or two, when in reality - properly doing is way much longer
- Trial work is subject to payment in most jurisdiction, so it is very unfair to ask for unpaid trial work. Imagine for example anywhere to get an electrician or a shop assistant to do a work and not pay them at the end of the day. Now this is happening to software engineers, what is a nonsense
- Also, I protest against employing not fully and appropriately educated IT staff. A trade license is needed to pour concrete, but no license is needed to write software. So, a person who makes a faulty foundation for a residential home can be called out for not having a license but an IT worker who makes a bug for which worldwide IT systems go down and you cannot shop for Woolworths or board an airplane for hours cannot be penalized or banned for making such mistake. That is insane
