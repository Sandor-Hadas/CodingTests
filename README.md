# CodingTests
Just to make sure - I am not going to write any coding test again unless paid for, especially because:
- Some coding tests look to be individually usable parts. Most of them then are used in a way that is fully out of my control. I know more than two people who told that this is an optimal way to outsource coding jobs so that they are done in the applicants best fashion, they receive the code and pay nothing. They even ask the person doing the code to put it on github or such so it goes under GPL/LGPL or another publicly permissible license so it can be fully utilized without agreement of the creator
- That kind of take away coding tests take several hours or some days to write, so it is way behind reasonable and necessary assessment of skills, especially if a short contract or a job having a probation period is offered. The interviewer often says to do a test, just an hour or two, when in reality: properly doing it is way much longer
- Trial work is subject to payment in most jurisdictions. That is fair. So, it is very unfair to ask for unpaid trial work. Imagine for example getting an electrician or a shop assistant to do a day of trial work and not pay them at the end of the day. Now this is happening to software engineers, what is a nonsense
- Also, I protest against employing not fully and appropriately educated IT staff. A trade license is needed to pour concrete, but no license is needed to write software. So, a person who makes a faulty foundation for a residential home can be called out for not having a license but an IT worker who makes a bug for which worldwide IT systems go down and you cannot shop in Woolworths or board an airplane for hours cannot be penalized or banned from the field for making such a mistake. That is insane
